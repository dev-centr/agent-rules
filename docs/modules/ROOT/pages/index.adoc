Canonical **forkable** rules and profiles for coding assistants under Dev-Centr. Content is meant to be read by agents from disk or pasted into an app rules field.

Repository::
https://github.com/dev-centr/agent-rules

Docs::
https://docs.devcentr.org/agent-rules/

== What this is

* Shared end-user / project agent instructions (`user.md`, `general/`, `profiles/`)
* **Harness-neutral** templates — machine/harness facts in `$CODE_ROOT/harness.md` and `$CODE_ROOT/machine.md`
* Assembled locally (paste or via rules-manager)
* Optional on-demand agent skills under `skills/` — start at xref:bootstrap.adoc[Bootstrap agent skills]

== Start here

* xref:editorial-titles.adoc[Editorial titles] — cold-reader gate, enthymemic titles, agent self-test
* xref:case-study-agent-voice-vs-reader-voice.adoc[Case study: agent voice vs reader voice] — URL-identity rewrite as a cautionary tale
* xref:harness-neutral.adoc[Harness-neutral architecture] — **rules geography** map (layered deltas; personal fork is not HEAD parity)
* xref:changelog.adoc[Changelog] — functional history (including layer renames)

== What this is not

* **Not** Dev-Centr product automation — that lives in https://github.com/dev-centr/devcentr-agent-rules[`devcentr-agent-rules`]
* **Not** a place for workstation constants — keep those in `$CODE_ROOT/machine.md` and `$CODE_ROOT/harness.md`
* **Not** always-on dumping ground for long curricula — those belong in skills (see `skills/BOOTSTRAP.md`)
