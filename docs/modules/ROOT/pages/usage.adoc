= Usage

. Clone into your code hive, for example `$CODE_ROOT/github.com/<your-org-or-user>/agent-rules`.
. Point your assistant at `RULES.md`, or compose with https://github.com/dev-centr/rules-manager[`rules-manager`].
. Put machine-local facts in **`$CODE_ROOT/MEMORIES.md`** (never commit). Format: `MEMORIES.example.md` in this repository.
. Optional: install Cursor skills from this repo — shop file link:https://github.com/dev-centr/agent-rules/blob/main/skills/BOOTSTRAP.md[`skills/BOOTSTRAP.md`] · Antora xref:bootstrap.adoc[Bootstrap Cursor skills] · org identity skill xref:skills-catalog.adoc[bootstrap-org].

Fork the repository when you need private constants. Upstream portable improvements with pull requests to `dev-centr/agent-rules`.
