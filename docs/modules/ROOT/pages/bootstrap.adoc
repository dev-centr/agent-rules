== Quick rules

* Curricula under `skills/<name>/` are **not** part of `MAIN.md` / `user.md` context assembly.
* Install per `$CODE_ROOT/harness.md` (`SKILLS_DISCOVERY_ROOT`, `SKILLS_INSTALL`) or read `$AGENT_RULES_PATH/skills/<name>/SKILL.md` directly.
* Always-on rules / `user.md`: one-line pointer at most.
* Titles + Nieman anti-terse tips stay in `general/documentation.md`.
* First-time setup: skill `harness-setup`.
