== Policy

* **One skill per job** — separate `writing-news` and `writing-blog`, not a combined router skill
* **`description`** is trigger words (utterances, filenames, task phrases) — not a lay summary of the skill. Skill `write-a-skill`.
* Junction canonical tree into `~/.cursor/skills/<name>/`
* Update `CATALOG.md` on every add/move/deprecate

== Registered (org)

[cols="1,2",options="header"]
|===
| Skill | Triggers on

| `writing-news`
| News item, ship note, org announcement, news-channel body

| `writing-blog`
| Blog post, essay, philosophy, thinking-in-public body

| Mojibake, SVG Encoding/EntityName errors, post-edit Antora SVG/adoc on Windows

| "publish to dub", "publish to dlang", "publish dlang"; DUB categories; register a D package on code.dlang.org

| Bootstrap or initialize an org or project; GitHub organization; company/nonprofit; library/CLI/desktop/Tauri/SolidStart; `.github`; named or pasted SDL profile; house `{org}/agent-rules` overlay (pointer, not a submodule)

| `tag-release`
| Tag a release; ship `vX.Y.Z`; rolling GitHub `v2`/`v2.x`; `+` dual-axis labels; pin vs float

| `write-a-skill`
| Author/edit a Cursor skill, `SKILL.md`, skill `description`; trigger words vs lay blurb; how to write skills

| `ship-app`
| Scaffold/ship a GUI, CLI, TUI, library, game, or service; Software Product Essentials

| Antora site or docs hub; Lunr; one public site per org; Valentus (confirm)

| `public-readme`
| Public README.md / README.adoc; Best-README chrome

| `draft-pr`
| Open or draft a pull request; `gh pr create`

| `git-commit`
| Create a git commit when asked

| `owned-changelog`
| Changelog / changelog-details on an owned project

| `env-names-registry`

| Context7 unavailable; local library-docs fallback

| `issue-reports`
| Draft/file an issue report; never chat-only

| `polyglot-ci`
