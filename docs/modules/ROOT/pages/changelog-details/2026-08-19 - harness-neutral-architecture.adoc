= 2026-08-19 — Harness-neutral architecture

* Documented the split: forkable policy in `user.md` / `AGENTS.md` / `general/*`; paths and harness wiring only in machine-local files.
* Satellite orgs pick up shared changes by `git pull` on the canonical `dev-centr/agent-rules` clone (pointer wrappers, not submodule pins).
