== Summary

Named DevCentr's lightweight agent harness **Hornet** and its model-routing meta-agent **Mixr** (Cursor *Auto*-shaped).

* No single default model — Mixr assigns `{ model, provider, budget }` per node/job
* `HARNESS_NAME = hornet` added to harness-neutral enum
* Proposed variables: `MIXR_ROUTING`, `MIXR_ROUTER_MODEL`, `MIXR_DEFAULT_POLICY`
