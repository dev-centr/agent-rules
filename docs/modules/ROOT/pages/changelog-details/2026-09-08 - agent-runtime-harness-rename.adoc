== Summary

The DevCentr agent runtime's former **Hornet** working name is retired.
Its repository, package, CLI, and provider identity now use the generic name **harness**.

Active architecture pages now use `HARNESS_NAME = harness`, `harness serve`, and the `HarnessDriver` integration name.
Historical changelog entries retain Hornet where it identifies the name used by an earlier release.

**Cricket** remains reserved as a possible name for a model, coordinator voice, or advisory policy layer.
It is not the runtime name.
