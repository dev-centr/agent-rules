== Summary

* Skill `demo-site-wiring`: when per-variant mockups are not replaced on select, put them **inside** the tab faces (label + mockup).
* The tabpanel is the first region whose content actually changes (variant title / blurb / desk).
* Do not leave a separate static mockup band that reads as content above the real tabpanel.

== Why

A label tab row plus a second mockup row that never swaps looks like two content bands. Mockups that only select a variant are chooser chrome, not tab content.
