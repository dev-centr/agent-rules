Cloud Agent / platform defaults often open PRs as draft. That preference is wrong for this house: reviewers should see ready PRs unless someone explicitly asked for draft.

* Skill `draft-pr`: create/update as ready (`draft: false`); no `--draft` unless asked; `gh pr ready` if the platform still opened a draft.
* Portable one-liner in `user.md` / User Rules and `general/pull-requests.md`.
* Do **not** copy this into every repo `AGENTS.md` — that layer is for project facts, not portable process prefs.
