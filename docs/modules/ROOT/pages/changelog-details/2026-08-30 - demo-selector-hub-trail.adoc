== Summary

* Skill `demo-site-wiring`: multi-variant default is a **selector hub** whose tiles open **separate variant pages** (Context Edge / virtual-pages). No interactive desk on the hub. In-page tabs are a narrow exception.
* Identity strip must include **intermediate site crumbs** (typical: Org home → Demos → demo home → optional variant). Do not collapse Org + Demos into one crumb.

== Why

In-page tab systems for heavy desks work poorly on mobile. Separate pages match how Context Edge already ships. Breadcrumbs that skip Demos (or mislabel the org crumb as the demos index) hide the path that landed the reader on the demo.
