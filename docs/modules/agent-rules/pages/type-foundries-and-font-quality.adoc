Choosing a typeface and *loading* it on the web are separate decisions.
This page covers **foundry quality**, **licensing lanes**, and **engineering patterns**; runtime bundling stays in the portable rule `general/self-host-fonts.md` (skill `self-host-fonts`).

Agents: load skill **`typeface-selection`** when picking fonts; then **`self-host-fonts`** for Fontsource / local `woff2` and preload.

== Why one Colophon face on Google Fonts is misleading

Colophon Foundry ships a large **retail** catalog (**Aperçu**, **Basis Grotesque**, **Space Grotesk**, **Fortescue**, and others).
**DM Sans** on Google Fonts is a **commissioned open-source** companion derived from their commercial grotesk work — not the whole foundry output.

The type world splits into:

* **Foundry-direct / retail** — full families, optical masters, display/text cuts.
* **Open catalogs** — subsets, commissions, and product fonts (Google Fonts, Fontshare, etc.).

== Patterns in well-engineered families

. **Neo-grotesk / humanist hybrid** — geometric structure with humanist terminals so UI text does not read robotic at small sizes.
. **Optical sizing** — distinct Display vs Text masters (or a variable `opsz` axis): spacing, stem weight, and ink traps tuned per size range.
. **Historical model, digital redraw** — shapes informed by specimen history, corrected for screens.
. **Variable font architecture** — continuous weight/width (and often optical size) without mangled interpolations.

Generic free sans often ship one outline scaled everywhere — the “same style” as a retail face can still feel flat.

== Open catalogs (Google Fonts and peers)

=== How strong work appears for free

* **Paid commissions** — e.g. Colophon **DM Sans**, Production Type **Spectral**.
* **Product open source** — **Inter**, **Roboto**, **Fira** / **Fira Code** (built for a platform, not a foundry’s full retail line).
* **Foundry-selected releases** — e.g. TypeTogether (**Literata**, **Alegreya**), Dalton Maag (**Ubuntu**, **Lexend**).

Always read each family’s designer and license page — do not assume every popular Google Font belongs to one foundry.

=== Tradeoffs vs retail

* Optical sizing and feature richness may be narrower on free cuts (variable fonts help).
* Flagship retail fonts often stay off free catalogs by design (licensing is how boutique foundries sustain work).

== Paid vs OSS (user choice)

Dev-Centr **recommends** curated open faces for web and docs (see `catalogs/project-typefaces.sdl` in the agent-rules repo) but allows **retail** faces when the user holds a license.
Suite chrome (DevCentr Appearance) and **project** pins stay separate — link:https://docs.devcentr.org/platforms/devcentr/specifications/components/appearance.html[Appearance (code font)] vs link:https://docs.devcentr.org/platforms/devcentr/specifications/components/project-typography.html[Project typography (font lock)].

Project lock file: `.devcentr/fonts.sdl` with `preference` `oss`, `retail`, or `mixed`.
Policy: `general/font-project-lock.md` in agent-rules.
