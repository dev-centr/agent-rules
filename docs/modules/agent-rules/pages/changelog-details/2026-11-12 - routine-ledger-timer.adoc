== Routine ledger timer

Recurring work now has a shared record and a command that can pick it up from more than one harness.

* Skill `routine-ledger` tells an agent to register a routine instead of trusting chat memory, and how claims, watches, and missed runs work.
* JSON5 files under `schemas/routine-ledger/` are the contract. An `agent_bus` target names the harness door. `launch` is `wait` or `launch`.
* `dev-centr/routine-timer` reads that ledger. While it is running, the host is online. It reports when a named harness process appears.
* A due job is submitted with `agent-bus submit` only after that process is running. The default does not start the harness. `launch: "launch"` is opt-in and requires `launch_program`.
* `apply --install` registers the daemon at user logon, not at system boot.
