== Web UI design references, multi-harness sync, and hub auto-rebuild

Three portable policy and skill updates landed together:

* **Web UI design references:** added `skills/web-ui-design-references/SKILL.md` and `general/web-ui-design-references.md` (registered in `skills/CATALOG.md` and `user.md`). Directs agents asked for strong web design or UI inspiration to consult `general-knowledge` `reference/notable-web-ui-designs.adoc` (using each entry's date added and source Wayback Machine snapshot) alongside `reference/ai-site-design-contract.adoc`.
* **Multi-harness skill sync, Windows `PATH` truncation check, and dependency auto-install:** updated `skills/sync-agent-rules/SKILL.md`, `general/rules-skills-sync.md`, `general/windows.md`, and `harness.example.md`. Shared skills must be authored canonically under `$AGENT_RULES_PATH/skills/` and reconciled across all active harness discovery roots on a workstation. Before reporting a dependency CLI missing on Windows, agents compare process `PATH` against Registry `Machine` + `User` to detect Explorer `PATH`-length truncation, refresh session `PATH`, and auto-install missing ungated dependencies (`git-ai` evaluates the `git-ai-guest-repos` `#2399` gate before installing).
* **Dependent docs-hub rebuilds:** updated `skills/subscribe-docs-hub-rebuild/SKILL.md`, `skills/push-code/SKILL.md`, and `user.md`. Prefers GitHub Actions `repository_dispatch` (`notify-docs-hub.yml` + dispatch token) over agent-driven redeploys, while instructing agents to quietly trigger `docs-source-updated` after pushing `docs/**` changes and suggest CI wiring when automated hub notify is missing or unset.
