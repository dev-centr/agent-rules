Agents that needed a harness command the studio no longer exposes were inventing a fresh workaround in the chat. The skill now points at the catalog in `dev-centr/session-router`.

* `removed-features.md` is the file a reader offers a workaround from. `AGENTS.md` in that repo points at it.
* `session-router resolve` picks the door. The skill body does not copy the profile.
* Versions with no profile, and builds of commits between releases, use the newest older profile. `inherited=true` prints the repair checklist.
* The self-update is a fork of `dev-centr/session-router` and an upstream pull request that adds the version which failed. The harness itself is not the fork.
* The state-database door stays last. The skill tells the agent to repeat the warning and wait for a yes before `--worst-case --i-understand`.
