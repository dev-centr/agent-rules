== Collapsible AsciiDoc contents

Skill `public-readme` places the AsciiDoc table of contents in a `<details>` expander after the centered header, the same place the Markdown blank uses.

`:toc: macro` with `toc::[]` after the header puts the list under the badges and title. The macro sits between two passthroughs, because a passthrough does not expand macros. An empty `:toc-title:` leaves the generated title div with no text. The summary text is Table of Contents. The HTML5 converter still writes that empty div. Unsetting the attribute writes the word `null` in Asciidoctor.js 2.0.26.

On GitHub, a bare `:toc:` places the list above the header. `:toc: preamble` emits no list when the header is HTML rather than an AsciiDoc document title.
