== Feedback loops go to fbl

`abuse@` is the public contact a person or another postmaster writes to. A person reads it. It is not the inbox for feedback-loop aggregates, Postmaster Tools, or the hijack detector.

Automated ARF feedback loops go to `fbl@` on that domain. `fbl@` is not the published public contact. The detector reads `fbl@`. A spam complaint does not un-whitelist `mailer-daemon` and does not turn `abuse@` into a machine inbox.

Gmail does not send per-message ARF. Do not point Postmaster Tools at `abuse@`.
