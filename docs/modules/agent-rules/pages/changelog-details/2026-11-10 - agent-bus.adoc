The catalog that was `session-router` is `dev-centr/agent-bus`. The skill name is `agent-bus`.

* An agent drives a harness, including the harness it is already in.
* `layer=mcp` calls the harness MCP and does not add a second copy on the polyglot MCP.
* `layer=harness-commander` is the CLI wrapper, the release-keyed hack, and the warned state-database write.
* A failed inherited hack is still a fork and an upstream pull request of `dev-centr/agent-bus`.
