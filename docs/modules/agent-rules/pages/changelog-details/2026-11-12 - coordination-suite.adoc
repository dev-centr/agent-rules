== Coordination suite store

The shared store for agent plans is `dev-centr/coordination`. An agent opens a plan node. A wait row points at that node and records the estimate, the status, and the wait-hub id.

* Skill `plan-stack` names that database. The session `plan-stack.kdl` remains the file a person can read. `coordination import` loads it.
* After a workspace move, `coordination record-move` is the notification. The PowerShell location script remains the fallback that writes the file.
* The plan-stack wait queue mirrors a phase into the database and does not replace a title the plan tree already has.
