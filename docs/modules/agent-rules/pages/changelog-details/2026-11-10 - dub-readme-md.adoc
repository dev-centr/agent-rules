The DUB registry reads `/README.md` from the tagged commit and renders it as Markdown. It does not render `README.adoc`.

* `general/environment.md` and `user.md` name code.dlang.org next to npm. Do not rename or delete the Markdown file.
* Skill `public-readme` and skill `publish-to-dub` say the Markdown file is a real listing, because GitHub shows `README.md` when both files exist.
* The registry copy appears on the next SemVer tag, not when the file lands on the default branch.
