== Password login includes a reset

* `general/login-reset.md` is the rule. `user.md` carries the one-line pointer.
* Skills `bootstrap-org` and `ship-app` follow it when that work adds a password login.
* A website is one case. A desktop app, a CLI, a TUI, and a service follow the same rule.
