== Service manager standard

`general/service-manager.md` points at the OpenShellOrg page. The rules are not copied here. Skill `service-manager` is what an agent loads before writing a start command.

* A manager holds every instance, assigns `1` and `server 1`, and exits when the last instance is gone.
* Start detaches. `-listen` keeps output in that terminal. Status names the terminal that spawned each instance and the terminal that is showing it.
* A singleton stays one process and does not use that id space.
* Skill `openshell-cli` sends a CLI through prohelp. `help.sdl` is the only help text. A new D command uses prohelp-cli and arsd.cli.
