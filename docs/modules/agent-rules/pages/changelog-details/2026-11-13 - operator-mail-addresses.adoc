== Operator mail addresses

Each domain the organization controls gets `support@`, `postmaster@`, and `abuse@` at the apex. Those are operator destinations, not a username blacklist, and there is no catch-all.

`mailer-daemon@` is a platform address. It is delivered to the inbox and is not used to train a spam filter. Google once had a compromised mailer daemon that sent spam; after that spam was reported, later legitimate mail from the same address kept landing in spam. The whitelist stays.

The practice is `general/org-mail-addresses.md`. Skill `org-mail-addresses` applies it. Bootstrap points at that file when a new org owns domains.
