== Summary

Multitask / multi-subagent / harness swarm workers **commit locally** and defer `git push` to the coordinator after the wave, unless a worker needs the remote *now* to validate. Parents must put `GIT_CLOSEOUT=commit-only` in worker briefs and omit standing push authorization — Cursor often copies always-on rules into Task prompts.
