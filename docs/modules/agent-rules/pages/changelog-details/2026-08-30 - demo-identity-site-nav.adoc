== Summary

* Skill `demo-site-wiring`: the `org / repo` identity strip is **site navigation only**.
* Org crumb → demos index; repo crumb → this demo's Pages / suite home.
* The VCS logo line is the **only** chrome control that links to the GitHub/GitLab repository.
* Explicit do-not: do not make the repo crumb and the logo both open the VCS URL.

== Why

Linking the repo name in the breadcrumb to GitHub while also showing a GitHub mark below duplicated the destination and made the breadcrumb read as a second repo button instead of site nav.
