== Skip a static site when a homepage is imported

Init used to treat `{org}.github.io` as the org homepage even when the project already published a site on another host.

* Skill `bootstrap-org` generates the static site only when no homepage is part of the import.
* Netlify, Cloudflare Pages, Vercel, a custom domain, and another Pages site all count.
* The imported URL is the org website. A second static site, including a stub, is not created.
* Profile defaults record the gate as `generate "only-if-no-imported-homepage"`.
