== A spam complaint is an incident

Anything this organization controls that is reported as spam is investigated. That includes `mailer-daemon`, `support`, `postmaster`, `abuse`, `bounces`, any other address, the sending IPs, and the domains. The report is not a reason to blacklist the address or to drop the inbox whitelist.

The Spam button at Gmail, Yahoo, or Microsoft trains that provider's filter and does not forward the message. Platform addresses are not reported that way. `abuse@` is the public contact a person reads. Automated ARF feedback loops go to `fbl@`, which is not the published contact. Gmail does not send per-message ARF. Do not point Postmaster Tools at `abuse@`.

The attached original is compared to mail the platform sent. A foreign IP is forgery. A platform IP with no matching send is a hijacked credential or daemon. Record it. Leave the whitelist in place.
