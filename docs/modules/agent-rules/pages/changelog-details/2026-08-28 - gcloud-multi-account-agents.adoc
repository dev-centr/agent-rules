== Summary

* Expanded xref:gcloud-cli-agents.adoc[gcloud CLI for agentic workflows] with a multi-account section: accumulate vs replace, `gcloud auth list` / `gcloud config set account`, named configurations for org pairs (FTN vs DevCentr), agent check-before-admin, and what `auth revoke` / `logout` remove.
