== Agent coordinator command

Skill `plan-stack` names the command a person types for the shared plan.

* `agent-coordinator plan` is the plan tree, including `import`, `record-move`, `resolve`, and `repair`.
* `agent-coordinator schedule wait` writes the wait on a node. The column process on port 17358 draws those waits.
* When the database is down, that process keeps its JSON files. Those files are not the routine ledger.
