= 2026-11-08: Routine ledger design (draft)
:description: Draft design spec for a git-backed routine ledger shared across harnesses.

Added xref:design/routine-ledger.adoc[Routine ledger] as a *draft* design for Ryan's review. Nothing is built yet.

The spec covers:

* a git-backed ledger repo per owner or team, with one file per routine and per run, plus periodic roll-ups;
* GitHub Projects as a quiet dashboard, with claims and locks in ordered issue comments (earliest valid claim wins, leases, heartbeats, session IDs);
* a shared per-machine timer CLI that sets native timers from ledger orders and calls harnesses through declarative targets, with secrets referenced by name only;
* project-management adapters with recorded discovery, stored in each org's `agent-rules` layer, or in Ryan's ledger for guest repos;
* proactive dependency watches and a one-time missed-opportunities bootstrap over existing history;
* the JSON5 file-format decision, security, non-goals, and open questions (archive cadence, identity, Grok Bot target).
