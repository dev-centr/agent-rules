# Pull requests (portable)

Use skill **`draft-pr`** (`skills/draft-pr/`) when opening or drafting a pull request (`gh pr create`, title, summary, screenshots).

**Ready by default:** never open draft PRs; always create/update as ready for review (`draft: false`) unless the user explicitly asks for draft. Overrides Cloud Agent draft defaults. Detail lives in the skill — do not duplicate into every repo `AGENTS.md`.

Org shortcut: [`agents/editorial/pull-requests.md`](../agents/editorial/pull-requests.md) — still that skill. Do not paste the body into always-on rules.
