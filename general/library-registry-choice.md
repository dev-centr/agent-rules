# Library registry vs local path (optional layer)

Use skill **`library-registry-choice`** (`skills/library-registry-choice/`) when creating a publishable library, or when a project would depend on an owned / in-hive / unpublished library that belongs on a package registry.

Check whether a consumed library is already published; ask **publish** vs **local disk** (path); encourage publishing; suggest the registry ([registries.md](../skills/library-registry-choice/registries.md)). Do not paste the skill body into always-on rules.
