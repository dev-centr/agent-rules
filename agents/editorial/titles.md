# Editorial titles (org default)

When writing or editing **news** or **blog** titles in Dev-Centr sites, follow each site’s `STYLE.adoc`. Shared short form for `docs`, `devcentr.org`, and Antora components.

## Voice

- **News** — outward shared record; subject + present-tense verb (headline present).
- **Blog** — inward: ideas, philosophy, tutorials, thinking in public.
- **Essay with an action** — implied **[On]** test (gerund / parallel); not bare imperatives.
- **Essay claim without a verb** — OK for theses.
- **Antora topic titles** — concept names; no forced verb.

## Stance

- Sentence case; accurate; not a whitepaper section label dressed as news.
- First-party news omits the org name unless another actor did the action.
- Prefer `X as Y` / process / *when* / disproof / questions over rigid `X is Y`.
- Attach floating modifiers to an object.
- Philosophy: **Titles as orientation** (not MEMORIES).

## Body copy

- **News body** → Cursor skill `writing-news` (junction from `skills/writing-news/`).
- **Blog body** → Cursor skill `writing-blog` (junction from `skills/writing-blog/`).
- Nieman anti-terse checklist stays in `general/documentation.md` (thin always-on layer).
