# Pull request voice (org default)

When opening PRs for Dev-Centr work **or** drafting upstream gifts from this org’s guidance, use skill **`draft-pr`**.

Short form:

- **Ready by default:** never `--draft` unless the user asks; mark ready if the platform still opened a draft.
- **Title:** simple language; orient the reviewer.
- **Intro:** plain English, inviting; lead with the human problem; short bullets; invite feedback.
- **UI changes:** before/after screenshots at minimum.
- Tone: gift to maintainers, not a lecture.

Site news/blog titles remain in `editorial/titles.md` (canonical). Site `STYLE.adoc` is a thin pointer only if present.
