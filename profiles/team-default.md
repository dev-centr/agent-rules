# Dev-Centr team profile (template)

Org-level constants — pair with a personal machine profile (`profiles/my-laptop.md` etc.) for `CODE_ROOT`, `ENVIRONMENT`, personal `ISSUES_REPO`.

```text
ORG = dev-centr
AGENT_RULES_PATH = $CODE_ROOT/github.com/dev-centr/agent-rules
DOCS_HUB = https://docs.devcentr.org
TEAM_DOCS = https://team.docs.devcentr.org
ISSUES_WORKFLOW = optional — often personal ISSUES_REPO in your profile
```

Personal fork example: keep portable customizations in your fork; still load org `AGENTS.md` from `dev-centr/agent-rules` (or merge via rules-manager with org winning on conflict).
